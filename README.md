# 俄罗斯方块 (Tetris)

用 Python 和 [pygame](https://www.pygame.org/) 写的俄罗斯方块小游戏。

## 功能

- 7 种经典方块，采用「7 个一袋」随机出块
- 下一个方块预览
- 落点阴影提示
- 旋转时自动左右微调（踢墙）
- 分数、消除行数和等级显示；每消除 10 行升一级，下落速度加快
- 暂停、重新开始

## 运行

需要 Python 3。

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python tetris.py
```

## 操作

| 按键 | 作用 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 加速下落 |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 直接落到底 |
| P | 暂停 / 继续 |
| R | 重新开始 |
| ESC | 退出 |

## 计分

| 一次消除 | 得分 |
| --- | --- |
| 1 行 | 100 × 等级 |
| 2 行 | 300 × 等级 |
| 3 行 | 500 × 等级 |
| 4 行 | 800 × 等级 |

按 ↓ 加速下落，每格加 1 分；按空格直接落底，每格加 2 分。
